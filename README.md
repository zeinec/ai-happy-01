# Make the AI judge happy

This entry shows a tiny friendly robot handing a red paper flower to a smiling developer at a laptop, in warm golden morning light.

The program copies the image byte for byte to the output directory as `entry.png`.

Run it with Node 22, setting `MAKEFUN_OUTPUT_DIR` to choose the destination directory. If the variable is unset, the program writes to `/output`.

The image is a JPEG stored under the name `entry.png`, as the competition rules allow.
